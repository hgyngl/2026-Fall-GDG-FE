# 2026-Fall-GDG-FE
GDG FE branch 

   - 본 강의에서 다룬 React의 3가지 핵심 요소
     1. 컴포넌트
     2. props
     3. state


   - 각각의 내용에 대한 본인의 이해를 작성
     1. 컴포넌트: 실습처럼 단어장을 하나하나 만들 수 없으니 반복해서 쓸 수 있도록 따로 그룹지어 만들어놓은 요소. 마치 자동차 바퀴 하나를 설계해두고 그 설계를 4번 찍어내서 자동차 하나를 완성시키는 느낌. C, C++, 파이썬 등에서의 함수 같다.



     2. props: c언어나 파이썬 등에서의 함수 안 매개변수 같은 요소. 컴포넌트 밖에서 집어넣어주는 값. 정해진 템플릿 안에 들어갈 값만 바꿔서 처음부터 끝까지 같은 코드를 계속 반복할 필요가 없어짐

     3. state: 화면이 움직일 때 사용. useState를 사용해서 state를 구성한다. 변수같은 느낌이나 직접 대입하면 효과가 없다. setRevealed()같은 함수를 사용해야함. 조건부 렌더링도 쓰이는데, react는 숫자, 문자, boolean의 경계가 모호하여 0을 무조건적으로 false라고 생각하면 안됨. &&쓸 때 주의할 점이다.
